Rest API 만들어보기

▼ 게시판 목록(페이지번호)

제목 게시판 목록 조회 [Test]
요청주소 http://localhost:8282/restBoardList.do
요청방식 GET
파라미터 이름 값 설명
pageNum 1 페이지 번호
설명 페이지 번호를 기준으로 게시글 목록을 조회한다.

▼ 게시판 목록(검색)

제목 게시판 목록 조회 (검색) [Test]
요청주소 http://localhost:8282/restBoardSearch.do
요청방식 GET
파라미터 이름 값 설명
searchField title 검색 기준 (title, content 등)
searchWord 검색어 검색할 키워드
설명 검색 조건에 맞는 게시글 목록을 조회한다.

▼ 게시물 열람

제목 게시물 상세 조회 [Test]
요청주소 http://localhost:8282/restBoardView.do
요청방식 GET
파라미터 이름 값 설명
idx 100 게시물 고유 번호
설명 해당 게시물의 상세 내용을 조회한다.

▼ 게시물 작성

제목 게시물 등록
요청주소 http://localhost:8282/restBoardWrite.do
요청방식 POST
파라미터 이름 값 설명
name 홍길동 작성자 이름
title 제목입니다 게시물 제목
content 내용입니다 게시물 내용
설명 게시물을 등록한다. POST 방식으로 요청하며, 테스트는 Postman을 사용한다.
